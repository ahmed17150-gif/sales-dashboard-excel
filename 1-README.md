# Excel Sales Dashboard

This is a beginner Excel project I worked on while following my instructor in the Route Academy Data Analysis course. I used a 1,000-row sales training dataset to practice formulas, PivotTables and dashboard sheets. This is coursework, not data from my past employers or a report for a real business.

## What I practiced

- Counting and conditional calculations with COUNT, COUNTA, COUNTBLANK, COUNTIF/COUNTIFS, SUMIF/SUMIFS and AVERAGEIF/AVERAGEIFS.
- PivotTables to summarize sales by region, product category, month, payment method and sales channel.
- Dashboard home and overview sheets with charts and slicers.

## Files

- [sales_dashboard.xlsx](sales_dashboard.xlsx): my coursework workbook, including the data, formula exercises, PivotTables and dashboard sheets. Personal author/editor metadata has been removed for sharing; the worksheet content is unchanged.
- [sales_data.csv](sales_data.csv): a values-only export of the 13 source columns in the `sales_data` sheet. Dates are written as `YYYY-MM-DD`; the extra formula-practice columns are not included.

## Key findings

The results I found in the training data are:

| Measure | Result |
| --- | ---: |
| Total sales across 1,000 records | 5,019,265.23 |
| Highest-sales region | North: 1,369,612.51 |
| Highest-sales product category | Clothing: 1,313,474.36 |
| Highest-sales calendar month | January 2023: 476,092.36 |
| Highest-sales payment method | Credit Card: 1,757,563.52 |
| Highest-sales representative | David: 1,141,737.36 |

November 2023 had sales of 467,482.90, which was below January 2023. The workbook's month-name PivotTable combines January 2023 and January 2024 into one January total of 495,420.37.

## Notes on the data

- The source dates run from January 1, 2023 to January 1, 2024. Some dashboard titles still show the course template's 2025-2026 label, not the actual data period.
- The workbook retains some course-template branding. It does not represent a project commissioned by that brand.
- Sales figures are reported as supplied; the dataset does not specify a currency.
- To view the charts and use the slicers, download the workbook and open it in Microsoft Excel. GitHub does not display the interactive workbook dashboard.
